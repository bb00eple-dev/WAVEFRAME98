WAVEFRAME 98 PWA 설치 문제 안내

앱 내부 설치 버튼을 눌렀을 때 설치 창이 열리지 않는 경우:
- HTTPS의 GitHub Pages 주소인지 확인합니다.
- Android Chrome에서 열었는지 확인합니다.
- 배포 후 새로고침하여 service-worker.js v2를 적용합니다.
- Chrome이 beforeinstallprompt 이벤트를 제공하지 않으면 웹페이지 버튼으로 강제 설치할 수 없습니다. 이때 Chrome ⋮ 메뉴의 앱 설치/홈 화면에 추가를 사용합니다.

이 패키지는 APK가 아닙니다. Android Chrome의 PWA 설치 기능을 사용하는 웹앱입니다. 실제 설치 여부는 배포된 GitHub Pages 사이트와 기기에서 확인해야 합니다.
