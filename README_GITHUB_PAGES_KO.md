# WAVEFRAME 98 · GitHub Pages / 설치형 앱 패키지

레트로 픽셀 UI 버전(V5.1)을 GitHub Pages에 게시하고 Chrome에서 설치할 수 있도록 만든 정적 PWA 패키지입니다.

## 1) GitHub에 올리기

1. GitHub에서 새 저장소(repository)를 만듭니다. 예: `waveframe98`
2. 이 ZIP을 PC 또는 휴대폰에서 압축 해제합니다.
3. 압축을 푼 폴더 **안의 파일과 폴더 전체**를 저장소 최상위(root)에 업로드합니다. `index.html`이 최상위에 보여야 합니다.
4. 저장소의 **Settings → Pages**로 이동합니다.
5. **Build and deployment → Source**에서 `Deploy from a branch`를 선택합니다.
6. Branch는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.
7. Pages가 게시되면 표시되는 `https://계정이름.github.io/저장소이름/` 주소로 접속합니다.

GitHub Pages의 공개 범위와 사용 가능 여부는 GitHub 계정 및 저장소 요금제 설정에 따라 달라질 수 있습니다. Pages 사이트는 인터넷에 공개될 수 있으므로 개인 음악이나 민감한 파일을 저장소에 올리지 마세요. 이 패키지에는 편집용 HTML·아이콘만 포함되어 있고 사용자 미디어 파일은 포함하지 않습니다.

## 2) Chrome에서 앱 설치

1. GitHub Pages 주소를 **Chrome**으로 열고 첫 접속을 완료합니다.
2. 주소창 또는 앱 화면의 `앱 설치` 버튼을 확인합니다.
3. 버튼이 표시되지 않으면 Chrome 오른쪽 위 `⋮` 메뉴에서 `앱 설치`, `설치 및 바로가기 만들기` 또는 `홈 화면에 추가`에 해당하는 항목을 선택합니다. 메뉴 문구는 Chrome 버전에 따라 다를 수 있습니다.
4. 설치 확인을 누르면 홈 화면/앱 목록에서 WAVEFRAME 98을 실행할 수 있습니다.

설치 메뉴가 바로 나타나지 않으면 GitHub Pages의 HTTPS 주소인지 확인하고 페이지를 새로고침한 뒤 다시 확인하세요. 브라우저가 설치 가능 여부를 판단하는 데 시간이 걸릴 수도 있습니다.

## 3) 오프라인 동작

- 서비스 워커가 앱 화면, 매니페스트, 아이콘을 캐시합니다.
- 한 번 온라인으로 연 뒤에는 앱의 기본 화면을 오프라인에서도 다시 열 수 있습니다.
- Galmuri 픽셀 폰트는 jsDelivr에서 불러오며, 온라인에서 한 번 로드되면 서비스 워커가 캐시를 시도합니다. 최초 오프라인 실행에서는 폰트가 대체 글꼴로 보일 수 있습니다.
- 편집 기능 중 음악·영상 내보내기, 미디어 코덱, 파일 저장 등은 브라우저 기능에 따라 오프라인 또는 기기별 제한이 있을 수 있습니다.

## 4) 프로젝트와 미디어 데이터 주의

- 디자인 프리셋과 요소 잠금 설정은 해당 브라우저의 로컬 저장소에 저장됩니다.
- `프로젝트 저장`은 편집 설정을 `.waveframe.json` 파일로 내보내는 백업 기능입니다. 현재 이 버전에는 해당 JSON을 다시 불러오는 기능이 없으므로, 파일은 설정 참고용 백업으로 보관하세요.
- 업로드한 음악·앨범 이미지·배경 이미지는 현재 앱에서 임시로 사용됩니다. 앱을 닫았다가 다시 열면 미디어 파일을 다시 선택해야 할 수 있습니다.
- 이 저장소에는 음악, 영상, 앨범 이미지 등 개인 미디어를 업로드하지 마세요. GitHub Pages에 올린 파일은 사이트를 보는 사람에게 공개됩니다.

## 파일 구성

- `index.html` : WAVEFRAME 98 V5.1 Pixel 앱
- `manifest.webmanifest` : 설치형 앱 이름, 아이콘, 실행 모드
- `service-worker.js` : 앱 셸 오프라인 캐시
- `icons/` : Android/Chrome 및 홈 화면 아이콘
- `.nojekyll` : GitHub Pages 정적 파일 처리용

## 업데이트

새 버전의 `index.html`과 관련 아이콘/매니페스트/서비스 워커 파일을 저장소에 덮어쓴 뒤 커밋하면 됩니다. 새 캐시 버전이 활성화되면 이전 WAVEFRAME 캐시는 자동 정리됩니다.
