# WAVEFRAME 98 · FIX7

WAVEFRAME 98 모바일 웹 음악·가사 영상 편집기입니다. GitHub Pages에 배포하고 Android Chrome에서 PWA로 설치할 수 있습니다.

## FIX7 변경점
- **4초 타임라인 오류 보강:** MP4의 일반 길이 정보뿐 아니라 fragmented MP4의 `moof / tfdt / trun` 조각 타임스탬프와 샘플 길이를 합산합니다. 업로드된 테스트 MP4는 전체 길이 246.483초로 계산됐습니다.
- **앱 내부 프로젝트 보관함:** 현재 작업 자동저장, 직접 저장, 여러 프로젝트 생성·불러오기·복제·삭제를 지원합니다.
- **미디어 자산 분리 저장:** 음악, 커버, 배경, 스티커 파일은 IndexedDB의 미디어 저장소에 한 번 보관하고, 자동저장 시에는 프로젝트 설정과 참조 정보 위주로 갱신합니다.
- **사진 스티커:** 사진과 투명 PNG 추가, 미리보기에서 이동, 크기·회전·불투명도 조절, 잠금·복제·삭제를 지원합니다.
- **가사 정렬:** 시간순 또는 불러온 순서대로 보기. 정렬을 바꿔도 실제 타이밍과 가사 내용은 변경되지 않습니다.
- 기존 FIX6의 PWA 설치 아이콘 위치와 GitHub Pages 경로 구조를 유지합니다.

## GitHub Pages 배포
1. ZIP 압축을 해제합니다.
2. 안쪽의 모든 파일과 폴더를 기존 GitHub 저장소 최상위에 업로드해 덮어씁니다. `index.html`이 저장소 최상위에 있어야 합니다.
3. 저장소 Settings → Pages에서 기존 배포 브랜치와 `/ (root)` 설정을 유지합니다.
4. 배포가 끝난 뒤 기존 HTTPS 주소를 Chrome에서 다시 엽니다. FIX7 서비스 워커가 새 앱 셸을 설치합니다.

## 앱 내부 저장 관련 안내
- 프로젝트와 미디어는 현재 기기·브라우저의 IndexedDB에 저장됩니다. 별도 프로젝트 파일을 내려받을 필요가 없습니다.
- 자동저장과 직접 저장을 모두 지원하며, 여러 프로젝트를 보관함에서 관리할 수 있습니다.
- 같은 기기와 같은 브라우저의 사이트 저장공간에서 이어서 사용할 수 있습니다. 계정 간 또는 다른 기기와의 자동 동기화는 포함하지 않습니다.
- 브라우저의 사이트 데이터/저장공간을 삭제하거나 기기를 초기화하면 프로젝트가 사라질 수 있습니다. 저장한 프로젝트가 중요하다면 브라우저 사이트 데이터를 삭제하지 마세요.
- 저장 가능 용량은 기기와 브라우저가 허용하는 범위에 따릅니다. 저장소가 부족하면 저장 실패 알림이 표시될 수 있습니다.
- 사진 스티커는 현재 사진의 크기·회전·불투명도·잠금 상태를 포함해 저장됩니다.

## 검증 범위
- JavaScript 구문 및 서비스 워커 구문 검사
- HTML ID 중복 및 고정 DOM 참조 검사
- manifest 및 아이콘 파일 경로 확인
- 업로드된 fragmented MP4 샘플의 조각 길이 합산 테스트
- Android 실기기에서의 실제 UI 조작, IndexedDB 복원, MP4 seek/재생 및 최종 렌더링은 이 환경에서 직접 실행할 수 없어 배포 후 확인이 필요합니다.
